Google Sheets

Automatically copy your daily Pomodoros and focus minutes to your own spreadsheet. Your history stays saved in Chrome, too.

Set up your spreadsheet
  1. In a Google spreadsheet, open Extensions → Apps Script.
  2. Replace the editor contents with the setup script. Save, select setup, and click Run. Authorize your script.
  3. Copy the sync key from the execution log. Keep it private: it authorizes writes to the Chromodoro tabs.
  4. Choose Deploy → New deployment → Web app. Execute as Me, allow access to Anyone, then deploy. The script checks your key; the spreadsheet itself stays private.
  5. Paste the web app URL and sync key below. If your work account blocks this deployment option, use CSV export from History instead.

Google Sheets backup is off. History is saved only on this computer.

Sync includes all existing history, then updates after focus sessions. Each Chrome profile gets its own tab. Sheet edits do not change your local history.
